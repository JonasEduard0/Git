# 🌿 Git: Comandos & Controle de Versionamento

Este repositório reúne **anotações sobre Git**, incluindo comandos e conceitos utilizados no controle de versão.

---

# 📚 Conteúdo do Repositório

O repositório contém **um arquivo `Git.md` com anotações e comandos do Git**.

## 📄 Anotações
  O arquivo inclui:
* comandos intermediários
* gerenciamento de branches
* manipulação de commits
* comandos de sincronização com repositórios remotos
* comandos de histórico
* resolução de conflitos

---

# 🧠 Conceitos Estudados

## 🔹 Fundamentos do Git

* o que é controle de versão
* repositórios locais e remotos
* commits
* histórico de versões
* rastreamento de arquivos

---

## 🔹 Branches

* criação de branches
* troca de branch
* merge de branches
* organização de desenvolvimento em paralelo

Comandos como:

* `git branch`
* `git checkout`
* `git switch`
* `git merge`

---

## 🔹 Repositórios Remotos

Comandos utilizados para interação com repositórios remotos:

* `git remote`
* `git push`
* `git pull`
* `git fetch`

---

## 🔹 Histórico e Controle de Versões

* visualização do histórico
* comparação de mudanças
* navegação entre versões
* recuperação de commits

---

## 🔹 Resolução de Conflitos

Estudo de situações como:

* conflitos de merge
* resolução manual de conflitos
* revisão de mudanças antes do commit

---

# 💻 Como Utilizar

O arquivo `Git.md` pode ser usado como **referência rápida de comandos Git** durante um desenvolvimento.
Basta abrir o arquivo e consultar os comandos quando necessário.
